# Метроном Cloud

Личный сервер клиента создаётся из `render.yaml`. Общий бот и Страж запускаются вместе через `cloud_runner.py` и используют две отдельные базы libSQL/Turso. Инструкция для владельца — в файле «ПРОЧИТАТЬ_СНАЧАЛА.txt» в установочном архиве.

Личные `api_id` и `api_hash` вводятся на странице клиентского сервера. На странице требуется `NODE_ACCESS_KEY` из Render Environment. Вместе с Telegram-сессией ключи включаются в зашифрованную копию для восстановления. Защищайте `NODE_SECRET` и `NODE_ACCESS_KEY`.

Render Free может засыпать и терять локальные файлы; самопинг не разбудит остановленный процесс. Сервис не гарантирует бесперебойность или нулевые расходы. Проверяйте лимиты и тарифы.

Архив проверен локально на имитациях; развёртывание и восстановление на реальных сервисах требуют отдельной проверки пользователем.
